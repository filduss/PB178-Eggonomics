# Eggonomics

is a .NET MAUI app created as project for pb178, it is meant to be an windows desktop app.

## Setup

to run the app its necessary to setup these variables:

dotnet user-secrets set "ConnectionString" ""

dotnet user-secrets set "SupabaseUrl" ""

dotnet user-secrets set "SupabaseKey" ""
